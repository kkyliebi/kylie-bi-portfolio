# Image Matrix — Round 01

**Status:** First-pass editorial selection  
**Purpose:** Establish a fast, evidence-led image system for the first job-ready portfolio release.  
**Scope:** TYRANNO; The Infinite Discussion; Audi Integrated Brand Communication; Deear Magazine; Madam, in Eden, I'm Adam

## 1. Selection principle

Images are not decoration. They are evidence.

Round 01 therefore selects image roles before selecting individual files. Each project receives a compact image package that must prove:

1. the project exists;
2. Kylie’s role is visible;
3. the communication logic can be understood quickly;
4. the final outcome is credible;
5. the project belongs to the same authored portfolio system.

The first release does **not** need exhaustive documentation. It needs a coherent and defensible edit.

## 2. Status key

- **A — Essential:** required for the first job-ready release.
- **B — Supporting:** useful when it adds distinct evidence.
- **C — Archive only:** historically useful but not needed in the first public edit.
- **HOLD:** do not publish before authorship, confidentiality, quality or factual status is resolved.
- **MISSING:** image role is required but no verified source asset has yet been identified.

## 3. Global image-role system

| Code | Image role | Function | First-release rule |
| --- | --- | --- | --- |
| H | Hero / project identity | Creates immediate recognition and establishes atmosphere | One strong image only |
| C | Context / question | Makes the problem or setting visible | Use when it clarifies the project faster than text |
| R | Research evidence | Shows observation, references, analysis or source material | Select only evidence that directly shaped the concept |
| D | Development / process | Shows transformation from research into system | Prefer sequences, iterations and annotated development |
| S | System view | Explains relationships, rules, structures or information architecture | Essential for system-led projects |
| O | Outcome | Proves the final object, experience, installation or campaign | Must be specific and publication-safe |
| E | Experience / scale | Shows audience, environment, interaction or real-world scale | Essential when spatial, live or experiential |
| X | Reflection / archive residue | Adds authorship, afterlife or historical depth | Maximum one per project in first release |

## 5. Round 01 selections

### 5.1 TYRANNO

**Editorial role:** Signature system project. It must prove research depth, visual-system construction and interaction—not merely a typeface aesthetic.

#### A — Essential

1. **H01 — Hero system image**  
   A single image combining one or more glyphs with the speculative human–T. rex communication context.

2. **C01 — 2050 coexistence context**  
   A concise world-building image, scenario frame or spatial proposition that explains why the communication system is needed.

3. **R01 — Behaviour / anatomy evidence**  
   Research material showing posture, movement, head, tail, gait or behavioural extraction.

4. **D01 — Glyph development sequence**  
   Sketch → abstraction → refined symbol. Prefer one coherent sequence over a wall of unrelated sketches.

5. **S01 — Core communication-system overview**  
   Classification, symbol families, behavioural logic or meaning structure.

6. **S02 — Static-to-motion relationship**  
   Still frames or diagram showing how gesture/movement becomes a readable symbol.

7. **O01 — Final glyph / type system**  
   Strong specimen or complete-system view.

8. **O02 — Interactive website / translator**  
   Only publish after its status is labelled accurately as complete, prototype or concept.

#### B — Supporting

9. **E01 — Learning / interaction flow**  
   Gamified learning, translation interaction or user flow.

10. **X01 — Thesis book / printed artefact**  
    Use if photographed clearly and it strengthens material credibility.

#### HOLD

- AR images unless clearly labelled as proposed or future development.
- Scientific imagery that implies unsupported certainty.
- Decorative dinosaur imagery that does not explain the communication system.
- Repetitive type specimens that add no new evidence.

### 5.2 The Infinite Discussion

**Editorial role:** Concept-led installation. It must make the shift from machine vision to machine perspective visible and distinguish the intended live system from the final synchronised simulation.

#### A — Essential

1. **H01 — Final installation overview**  
   The two computers inside the transparent enclosure, preferably with the spatial relationship immediately legible.

2. **C01 — Machine vision → machine perspective**  
   A concise diagram, annotated spread or visual transition explaining the conceptual reframing.

3. **D01 — Installation evolution**  
   Conference-room / talking-object concept → enclosure → two-computer installation. One edited sequence.

4. **S01 — Dialogue-system logic**  
   Two assigned identities, opposing positions, alternating listening / recognising / speaking states.

5. **O01 — Dual-interface conversation frame**  
   A clear frame showing captions and synchronised conversational states.

6. **O02 — Headphone listening experience**  
   Shows how the audience accesses the conversation.

7. **E01 — Installation in exhibition context**  
   A wide or medium shot proving scale, enclosure and audience position.

#### B — Supporting

8. **R01 — Rejected dashcam direction**  
   One compact piece only. Its role is historical: it explains the conceptual turning point, not a failed-project detour.

9. **X01 — Empty / residual installation image**  
   May support reflection if it adds stillness and does not become decorative filler.

#### HOLD

- Any caption calling the exhibited work a live AI conversation.
- Screens that cannot be distinguished from arbitrary chat mock-ups.
- Generic AI imagery, humanoid robots, neural-network graphics or cyberpunk visuals.
- Images implying that the AI independently chose its identities.

### 5.3 Audi Integrated Brand Communication

**Editorial role:** Professional credibility and real-world scale. The edit must show contribution across communication planning, creative production and execution coordination without overstating authorship.

#### A — Essential

1. **H01 — Portfolio-level Audi opener**  
   One publication-safe image that signals premium automotive communication and introduces the three-subcase architecture.

2. **O01 — Audi Channel**  
   One representative livestream / campaign frame with clear context.

3. **E01 — Audi Channel scale**  
   Studio, stage, production or audience evidence showing live communication complexity.

4. **O02 — Audi A8L Horch Global Premiere**  
   One launch image that communicates luxury positioning and cinematic narrative.

5. **E02 — Horch production / event scale**  
   Spatial, stage or execution view.

6. **O03 — Audi × Ryuichi Sakamoto**  
   One image that clearly communicates the cultural collaboration.

7. **E03 — Collaboration experience / installation / event**  
   Use only when publication rights and attribution are safe.

#### B — Supporting

8. **D01 — Communication proposal / narrative sequencing**  
   Select one redacted, publication-safe page or storyboard proving Kylie's planning contribution.

9. **S01 — Three-subcase map**  
   A simple editorial overview can replace excessive campaign screenshots.

10. **D02 — Production coordination evidence**  
    Timeline, call sheet, production board or behind-the-scenes documentation only when confidentiality permits and Kylie's contribution is clear.

#### C — Archive only

- Repetitive celebrity screenshots.
- Social metrics without verified source and context.
- Supplier documents, internal decks or client materials that expose confidential information.
- Generic car beauty shots that do not prove Kylie's role.

#### HOLD

- Any image without confirmed publication permission.
- Assets that imply sole creative direction, photography or campaign authorship.
- Uncredited third-party photography.

### 5.4 Deear Magazine

**Editorial role:** Editorial sensitivity, sequencing and the creation of a context for personal expression. The project must be represented through real publication structure, not generic magazine aesthetics.

#### A — Essential

1. **H01 — Cover or strongest opening spread**  
   Must establish Deear's actual identity and emotional register.

2. **D01 — Editorial sequencing**  
   A short series of consecutive spreads showing pacing rather than isolated favourite layouts.

3. **S01 — Typography / hierarchy system**  
   One image or paired spread showing how hierarchy supports reading and emotional rhythm.

4. **O01 — Complete publication object**  
   Cover, binding, thickness or printed form when available.

5. **O02 — Representative narrative spread**  
   A spread where image, text and sequencing work together.

6. **O03 — Second distinct spread family**  
   Must add a different narrative function, not merely another attractive layout.

#### B — Supporting

7. **C01 — Editorial premise / contribution context**  
   Only after title, premise, audience and authorship boundaries are confirmed.

8. **E01 — Reading / handling image**  
   Use if it communicates materiality and scale.

9. **X01 — Process residue or marked proof**  
   Useful when it shows editorial decision-making.

#### HOLD

- Claims of complete art direction, publication-system ownership or production leadership until confirmed.
- Layouts that cannot be publicly shown because contributor materials or personal narratives lack permission.
- Mock-ups that look stronger than the actual publication but distort the historical outcome.

### 5.5 Madam, in Eden, I'm Adam

**Editorial role:** Compact visual-narrative case proving storyboarding, symbolic composition, shoot execution, hand performance and post-production consistency.

#### A — Essential

1. **H01 — Signature photograph**  
   The strongest single image that carries the symbolic and emotional premise.

2. **O01 — Final sequence, image 1**  
   Beginning of the narrative.

3. **O02 — Final sequence, image 2**  
   Development or transformation.

4. **O03 — Final sequence, image 3**  
   Resolution, return or cyclical closure.

5. **X01 — Full edited sequence / contact-sheet view**  
   Proves pacing and should preserve the intended order.

#### B — Supporting

6. **D01 — Storyboard paired with final image**  
   Strong evidence of Kylie's authorship and translation from concept to shoot.

7. **S01 — Symbol / gesture relationship**  
   A close-up or annotated pairing when it clarifies the narrative.

8. **E01 — Shoot or hand-performance evidence**  
   Use only if visually strong and credits are clear.

#### HOLD

- Reordering the final sequence purely for visual variety.
- Claiming sole photography or creative direction before collaborators and camera operation are confirmed.
- Multiple near-identical colour grades.
- Generic fashion-editorial mock-ups that weaken the actual project.

## 6. First-round keep / cut decision

### Keep now

- Images that perform one distinct narrative role.
- Images that prove Kylie's thinking, contribution or execution.
- Images with clear publication status and sufficient quality.
- Real process evidence when it explains a meaningful transformation.
- Final outcomes photographed or captured in their actual context.

### Cut from the first release

- Duplicates and near-duplicates.
- Decorative mood images.
- Generic mock-ups used only to make the project look more expensive.
- Screenshots with unreadable interfaces or weak composition.
- Process walls containing many small items but no legible argument.
- Images that depend on long captions to become meaningful.
- Assets whose role, authorship, permission or historical status is uncertain.

## 7. Naming convention for the asset pass

Use this temporary naming system when source files are gathered:

`[PROJECT]_[ROLE]_[NUMBER]_[STATUS].[ext]`

Examples:

- `TYRANNO_H_01_KEEP.jpg`
- `INFINITE_D_01_KEEP.png`
- `AUDI_O_02_HOLD.jpg`
- `DEEAR_O_03_KEEP.tif`
- `MADAM_X_01_KEEP.jpg`

Allowed status suffixes:

- `KEEP`
- `MAYBE`
- `HOLD`
- `CUT`
