**Project Overview**
TYRANNO is a speculative communication project exploring how visual language systems could enable interaction between humans and Tyrannosaurus Rex within a future urban environment.
Combining semiotics, experimental typography, narrative world-building, and interaction design, the project investigates communication beyond human-centered linguistic structures.

**Core Concept**
A future-oriented communication system exploring interactions between humans and Tyrannosaurus Rex within a speculative urban environment.The project investigates how semiotics, experimental typography, and visual language systems can construct cross-species communication frameworks through narrative-driven world-building.

**Context / Question**
How might communication evolve when language must bridge radically different species, cognitive systems, and physical behaviors?
The project questions whether visual symbols, gestures, and narrative environments can function as alternative communication infrastructures in a speculative
future society.

**Concept Development**
The project was developed as a narrative-driven communication ecosystem rather than a traditional typeface design project.By combining symbolic structures, behavioral references, and speculative world-building, TYRANNO constructs a future-oriented visual language system designed around non-human perception, movement, and interaction patterns.

TYRANNO became an exploration of communication as a system rather than language as text alone.
